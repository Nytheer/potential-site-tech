# 📚 Minhas Tarefitas

O projeto permite adicionar tarefas e marcá-las como concluídas.

## Funcionalidades

- Adicionar novas tarefas.
- Adicionar tarefas pressionando o botão ou a tecla Enter.
- Marcar tarefas como concluídas.
- Interface simples e responsiva.

## Tecnologias utilizadas

![HTML5](https://img.shields.io/badge/-HTML5-black?style=for-the-badge&logo=html5)

## Objetivo

Praticar conceitos fundamentais de desenvolvimento web, como manipulação do DOM, tratamento de eventos, criação dinâmica de elementos e organização de código utilizando JavaScript.

## Aprendizados

Durante o desenvolvimento foram praticados conceitos como:

- Manipulação do DOM
- Eventos de clique e teclado
- Criação dinâmica de elementos
- Manipulação de classes CSS
- Estruturação de páginas HTML
- Organização entre HTML, CSS e JavaScript

## Como executar

1. Clone este repositório.

```bash
git clone URL_DO_REPOSITORIO
```

2. Abra o arquivo `index.html` no navegador.
